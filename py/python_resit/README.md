# Python — контрольные точки пересдачи

В репозитории находятся все 5 контрольных точек.

## Как запускать

### КТ1
```bash
python KT1_babushka.py
```

### КТ2
Откройте папку `KT2_hangman` и запустите:
```bash
python game.py
```

### КТ3
Откройте папку `KT3_csv` и запустите:
```bash
python main.py
```

### КТ4
```bash
python KT4_classes.py
```

### КТ5
Откройте папку `KT5_todo` и запустите:
```bash
python todo.py
```

Для КТ5 используется только стандартный Python и Tkinter, отдельные библиотеки устанавливать не нужно.
